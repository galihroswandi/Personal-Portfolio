Baywira is a platform for Indonesian micro and small vendors. A seller opens a shop, adds products, then shares a link or QR code. Customers scan it, pick products, and order without creating an account. Orders can be tracked by transaction ID, and the seller manages them from a dashboard.

I built it on my own across two repositories: a Next.js client (about 80 commits) and a NestJS API (about 260 commits since July 2024). The app itself is in Indonesian.

## What was built

![Three Baywira phone screens: the customer product storefront, order tracking, and the seller's order list. Sample data.](../../../assets/projects/baywira/baywira-mobile.webp)

The customer side: a product storefront, cart and order form, digital payment, and a tracking page that follows the order from creation to completion. A "Contact seller" button opens WhatsApp.

![The Baywira seller dashboard on desktop: revenue summary, quick actions, and incoming orders. Sample data.](../../../assets/projects/baywira/baywira-dashboard.webp)

The seller side: today's summary, orders grouped by status, products with several price options, payment method settings, and the shop QR code.

Every image on this page uses sample data from a local environment, not a real seller's data.

## Technical decisions

The app is a PWA used on phones. Write requests that fail while offline go into a queue in IndexedDB and are replayed when the connection returns. Requests that carry a file are not queued, because they cannot be stored in IndexedDB, so the user is told instead.

Stock is reduced when an order is created and restored if the order is cancelled. Unpaid orders expire through an hourly cron job that checks the payment token in Redis, so stock is not held by abandoned orders.

Ordering without an account is guarded by hCaptcha and a rate limiter. A seller's payment keys are stored encrypted (AES-256), and payment status and cart updates are pushed over WebSocket.

For sellers busy serving customers, there are voice commands to move between pages, voice input for the product form (for example "nasi goreng spesial, twenty thousand, stock fifty" in Indonesian), and swiping an order card to change its status.
