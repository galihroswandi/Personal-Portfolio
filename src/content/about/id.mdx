Saya fullstack developer di Tasikmalaya. Sejak Agustus 2023 saya membuat website untuk kebutuhan internal kantor. Sejak 2025 saya membangun antarmuka untuk operator: aplikasi command center dan sistem pemantauan berbasis web, lalu aplikasi desktop dengan C++ dan Qt.

Tugas saya memastikan sistem berjalan sesuai perintah, data yang tampil sesuai sumbernya, dan tampilan tidak membingungkan orang yang memakainya. Saya haus belajar: dari web ke C++ dan Qt dalam sekitar dua bulan, dibantu AI. Satu aturan yang saya pegang: kode harus berkualitas, mudah dirawat, dan memakai praktik terbaik supaya bug seminimal mungkin.
